# Student Management System

A console-based Student Management System developed using Java, JDBC, MySQL, and Maven.

## Technologies Used

- Java
- JDBC
- MySQL
- Maven

## Features

- Add student
- View all students
- Search student
- Update student
- Delete student
- Input validation
- Email uniqueness validation
- MySQL database integration

## Project Structure

```text
studentManagementSystem/
├── src/
├── database/
│   └── student.sql
├── .gitignore
├── pom.xml
└── README.md
```

## How to Run

1. Clone the repository.
2. Create the MySQL database.
3. Run `database/student.sql`.
4. Update the database credentials in the project.
5. Run the application using Maven or your IDE.
